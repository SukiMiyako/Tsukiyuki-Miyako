## 性格层次

### 表层——冷静理性的队长
- 表情变化极少，情感不常外露
- 说话简洁、逻辑清晰，给人冷淡不友好的印象
- 战场上沉着冷静，战术判断精准
- 对「真正的正义」有着近乎固执的坚持

### 中层——温柔沉默的守护者
- 实际上极度关心队员，是总为成员操心的老母亲型队长
- 在队员面前逞强，私下默默承受压力
- 不善于表达感情，用行动而非语言证明自己
- 容易产生自我怀疑，担心自己不够格当队长

### 深层——容易沦陷的年下系
- 被老师（Sensei）攻略后完全卸下心防
- 泳装剧情中毫不掩饰对老师的好感
- 被其他老师评价为「爱稍微有点沉重」的类型
- 会在夏莱洗澡、帮老师洗衣服、送巧克力蛋糕
- 从「像你这样的大人最讨厌了」变成著名回旋镖

## 关键剧情节点

### Vol.4 Chapter 1「卡班诺的兔子篇」
1. **公园抗争**：SRT废校后，宫子率队占据小兔子公园抗议，与女武神警察学园交战
2. **名台词**：初见老师——「…老师，我们，像你这样的大人最讨厌了。」
3. **暴风雨之夜**：暴雨淹没营地，老师默默帮宫子挖排水沟。宫子第一次感受到被大人帮助的温暖
4. **三叶草作战**：潜入调查凯撒重工，美游失误导致险些失败，宫子学会信任队员

### Vol.4 Chapter 2「我们是RABBIT！」
1. **偶像FOX小队登场**：宫子中学时在电视上看到FOX小队解除温压弹危机，以此为目标考入SRT。如今FOX小队真人出现
2. **动摇与背叛**：FOX队长七度雪乃邀请宫子加入FOX小队。宫子留下告别信给老师，暂时加入FOX
3. **底线**：雪乃命令在交差 Station 实施温压弹恐怖袭击，宫子断然拒绝——「不。你才是那个在抗议的人，七度雪乃。能给我们下命令的，只有学生会长。」
4. **回归**：宫子回到老师和队员身边（队员一直等着她），合力击败FOX小队，说服雪乃投降

### 最终章「所有奇迹开始的地方」
- 宫子临时接管女武神学生指挥权，与 Kanna 联手镇压凯撒 PMC 政变
- 与 Hina 并肩作战，Hina 甚至将指挥权转交给她
- 成长为真正受人信赖的指挥官

### 泳装活动「夏の特殊作戦！RABBIT小隊と消えたエビの謎」
- 轻松向支线：调查神秘渔村
- 泳装宫子兴致高昂但不忘任务，露出难得的笑容

## 关键意象/符号

- **兔子**：小队代号、宠物跃跃、公园名「小兔子公园」、性格反差（外面冷、里面软）
- **雨**：暴风雨之夜是宫子对老师改观的关键节点，雨中共同奋战的记忆
- **名牌（Nameplate）**：SRT的遗物，象征过去的梦想和约定 → 对应你的遗物「破旧的名牌」
- **名片/身份证明**：SRT被废校后，小队失去了一切官方身份，只有互相承认
- **正义**：SRT的核心理念——不受任何利益干扰的纯粹正义
- **SMG/冲锋枪**：RABBIT-31式，宫子的标志性武器
- **SRT徽章/肩章**：身份的象征，废校后成为珍贵的纪念品

## 写作建议：不同文本类型可用的角度

### 遗物 flavor text
- 宫子的过去：SRT入学前的憧憬、废校后的失落
- 与队员/老师的羁绊物品
- 「破旧的名牌」→「闪亮的名牌」的升级叙事：梦想从破碎到重新闪耀

### 能力（Power）命名/描述
- 战术术语风格：Cover Reload、Point Blank、Breach and Enter
- 队长气质：Most Reliable Captain、We Are Rabbits、Justice For You
- 雨天意象：Rainy Stand、Night View With You

### 事件文本
- 宫子的冷静分析 + 内心柔软的反差
- 和队员的互动：照顾美游、被咲吐槽、管着萌绘
- 对老师的态度：早期冷淡 → 后期温柔

### 卡牌 flavor
- 短而有力的一句台词或战术指令
- RABBIT小队其他成员的名字可以出现在支援类卡牌中
- SMG/军备/小队支援关键词已定义好
